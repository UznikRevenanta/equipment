УП — Разработка системы учета оборудования в учебной организации

Запуск: python equipment.py (Windows: py equipment.py, macOS/Linux: python3 equipment.py).
Нужен Python 3 с Tkinter. SQLite входит в стандартную библиотеку Python.
Проверка Tkinter: python -m tkinter. На Linux пакет Tkinter устанавливают средствами дистрибутива.
Файл equipment.sqlite3 создаётся рядом с программой. Распакуйте архив в папку с правом записи.

Демонстрация:
1. Нажмите «Новая карточка». Введите УЧ-001, Ноутбук, Компьютерная техника, 305,
   Иванов И. И. и статус «В эксплуатации». Нажмите «Сохранить».
2. Попробуйте повторно добавить УЧ-001 с другим названием. Программа предупредит о дубликате.
3. Выберите строку, измените кабинет или статус на «В ремонте» и сохраните.
4. Найдите карточку по слову «ноутбук» и выберите фильтр «В ремонте».
5. Нажмите «Экспорт CSV». В выгрузку попадут строки с учётом поиска и фильтра.
6. Закройте и снова откройте программу. Карточка и её изменения останутся в реестре.

Для вывода единицы из учёта используйте статус «Списано».
Для ошибочной записи выберите строку, нажмите «Удалить» и подтвердите.
Чтобы сохранить копию реестра, закройте программу и скопируйте equipment.sqlite3.
